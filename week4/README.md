# Week 4 — HTML & CSS Fundamentals

## Overview

Introduction to web page creation using HTML and CSS. Projects include structured HTML documents and a styled themed page with external CSS.

## Project Structure

```
week4/
├── unorderlist.html          # HTML unordered list demonstration
├── webpage1.html             # First basic HTML page with headings and paragraphs
│
└── webpage2/
    ├── pochiTheCat.html      # Themed page about a cat, with embedded image
    └── style.css             # External stylesheet for webpage2
```

## What Each File Does

### `webpage1.html`
A simple HTML document demonstrating headings (`<h1>`) and paragraphs (`<p>`). Covers the foundational structure of an HTML page.

### `unorderlist.html`
Demonstrates how to create unordered (`<ul>`) and ordered (`<ol>`) lists in HTML.

### `webpage2/pochiTheCat.html`
A themed multi-element page featuring a heading, an embedded image (base64-encoded), and content sections styled with an external CSS file (`style.css`). Demonstrates linking an external stylesheet.

## Concepts Covered

- HTML document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Headings, paragraphs, and text elements
- Lists: ordered and unordered
- Images (`<img>` tag, base64 embedding)
- Linking external CSS with `<link rel="stylesheet">`
- Basic CSS rules (selectors, properties, values)

## How to Open

Open any `.html` file directly in your browser:
```
Double-click the file, or drag it into a browser window.
```

No server or build step is required.
